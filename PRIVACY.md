# Privacy note for Dwell Time

Short version: the game does not collect anything about you.

- **No accounts, no servers, no network calls.** The production build is a
  single HTML file that runs entirely in your browser. It does not phone home.
- **Your progress is saved only on your device**, in your browser's local
  storage. It is never sent to anyone. Clearing your
  browser data or using the in-game "Erase save" button removes it.
- **Exporting a save** makes a file or a code that only you hold. The game does
  not upload it anywhere; it goes where you put it.
- **No analytics, no ads, no trackers, no third-party requests** at runtime.
  Fonts are built into the file, not fetched.

This note is accurate for the game as built in this repository. It is not legal
advice.
