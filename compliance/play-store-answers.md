# Play Store Submission Answers

Pre-filled for a **paid, offline, general-audience** game. Adjust the **crash/analytics** answers depending on whether you actually ship it. Only needed when you submit to Google Play (the $25 account).

## Data Safety form

Google asks what data your app **collects** (sent off the device) and **shares**.

| Question | If fully offline | If you add crash/analytics |
|----------|------------------|----------------------------|
| Does your app collect or share user data? | **No** | **Yes** |
| Data type collected | — | **Crash logs, Diagnostics** (and anonymous app-interaction data if used) |
| Is it linked to the user's identity? | — | **No** |
| Is it used for tracking? | — | **No** |
| Is collection optional? | — | **Yes** (opt-out in Settings) |
| Is data encrypted in transit? | — | **Yes** |
| Can users request deletion? | — | **Yes** (uninstalling removes local data; contact email for the rest) |

> Keep this honest and in sync with your privacy policy — mismatches get apps rejected or pulled.

## Content rating (IARC questionnaire)

For a non-violent arcade game, typical answers:

| Topic | Answer |
|-------|--------|
| Violence | None / cartoon only — answer truthfully for your game |
| Sexual content | None |
| Profanity | None |
| Controlled substances | None |
| Gambling | None (no simulated gambling, no loot boxes) |
| User interaction / shares location | **No** (offline, no chat) |
| Digital purchases | **No** (one-time paid app, no in-app purchases) |

Expected result: an **Everyone / PEGI 3 / ESRB E** style rating. The exact questionnaire output is official once you submit it.

## Store listing essentials

- [ ] App title and short description
- [ ] Full description
- [ ] App icon (512×512)
- [ ] Feature graphic (1024×500)
- [ ] At least 2–8 phone screenshots
- [ ] **Privacy policy URL** (public link — required)
- [ ] Category: **Games →** your genre
- [ ] Pricing: set your one-time price and the countries to sell in
- [ ] Target audience & content settings: **not** directed at children

## Pre-launch requirements for new personal accounts

- [ ] New developer accounts must usually run a **closed test with 12+ testers for 14 days** before production access. Plan for this — it's often the slowest step.
- [ ] Complete identity/D-U-N-S verification Google requests.
